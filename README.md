# Мюнхгаузен — настольная игра (веб-версия и Android)

Одна страница (`docs/index.html`) — это и есть игра. Из неё получается:
- **веб-версия** — открывается в любом браузере; через GitHub Pages даёт обычную ссылку;
- **Android-приложение** (APK, Android 8.0 и выше) — тонкая оболочка WebView, которая показывает ту же страницу.

```
docs/index.html            ← сама игра (веб-версия)
android/                   ← Android-проект (minSdk 26 = Android 8.0)
.github/workflows/build-apk.yml  ← сборка APK на GitHub
```

## Как залить на GitHub (с компьютера)

1. Распакуйте архив. Внутри папка `munchausen` — её содержимое и надо залить.
2. На github.com: **New repository** → имя, например, `munchausen` → **Create repository**.
3. **uploading an existing file** → перетащите ВНУТРЕННОСТИ папки `munchausen`:
   папки `android`, `docs`, `.github` и файлы `README.md`, `.gitignore`.
   В корне репозитория должны лежать именно они, а не вложенная папка `munchausen`.
   Если `.github` не видна — включите показ скрытых файлов (Windows: Вид → Скрытые элементы; macOS: Cmd+Shift+.).
4. Внизу нажмите **Commit changes**.

## Как залить с телефона (без распаковки на компьютере)

1. На github.com (в браузере телефона) создайте репозиторий.
2. **Add file → Upload files** → выберите сам файл `munchausen-github.zip` → **Commit changes**.
3. **Add file → Create new file**. В поле имени введите
   `.github/workflows/build-apk.yml` (косые черты сами создадут папки)
   и вставьте туда содержимое файла `build-apk.yml` из архива (текст приведён в ответе). **Commit changes**.
4. Сборка запустится сама. Workflow понимает и распакованные папки, и один zip в корне.

## Сборка APK

1. Вкладка **Actions** → запуск **Build APK** (запускается при каждом коммите; вручную: **Run workflow**).
2. Когда появится зелёная галочка (обычно 3–6 минут), откройте запуск → внизу **Artifacts** → `munchausen-apk`.
3. Скачайте, распакуйте zip — внутри `app-debug.apk`.
4. Перенесите на телефон и установите (разрешите «Установку из неизвестных источников» для приложения, из которого открываете файл).
   Приложение подписано отладочным ключом — этого достаточно для установки на свой телефон.

## Веб-версия по ссылке (GitHub Pages)

**Settings → Pages → Build and deployment → Source: Deploy from a branch → Branch: `main`, папка `/docs` → Save.**
Через минуту игра откроется по адресу `https://<ваш-логин>.github.io/<репозиторий>/`.

## Как обновить игру

Замените `docs/index.html` новой версией и сделайте коммит — GitHub сам соберёт новый APK
(Android-проект берёт страницу из `docs/`, отдельной копии нет). При желании увеличьте
`versionCode` в `android/app/build.gradle`, чтобы поверх старого приложения ставилась новая сборка.

## Если сборка упала

Откройте красный запуск в Actions → шаг, который упал → скопируйте последние строки лога и пришлите — поправлю.
Требования проекта: JDK 17, Gradle 8.7, Android Gradle Plugin 8.5.2, compileSdk 34 (всё ставится на GitHub само).
